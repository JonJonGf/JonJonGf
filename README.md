**Software · Hardware · Processamento de sinais**

Gosto de criar software que interage com hardware. Me interessa entender como as coisas funcionam por dentro e transformar isso em algo prático, leve e fácil de usar.

## Projetos em destaque

### 💡 Nexus RGB

Aplicativo de código aberto para controlar a iluminação do PC pelo Windows, pelo celular na rede local e pela Alexa. O Nexus tem um mapa 2D para criar efeitos no setup e controle opcional de ventoinhas que pode seguir a maior temperatura entre CPU e GPU. [Conheça o Nexus RGB](https://github.com/JonJonGf/nexus-rgb)

### 📡 Li-Fi com Transformada de Fourier

Projeto acadêmico de Sinais e Sistemas na UFF. O sistema usa ESP32 e um laser para transmitir coeficientes de Fourier e reconstruir a imagem progressivamente no receptor com Python e OpenCV. [Veja como o projeto funciona](https://github.com/JonJonGf/Fast-Fourrier-transform)
